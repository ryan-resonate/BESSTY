---
title: Workflow at a glance
section: Getting started
---

1. **Sources** — drop wind turbines, BESS pads and auxiliary equipment on the map. Pick the model from the catalog, or import your own.
2. **Calculation area** — set the rectangle of interest. Grid spacing auto-picks on first creation; tweak it in Settings.
3. **Receivers** — drop named receivers at sensitive locations. Set per-period limits.
4. **Barriers** — optional walls that diffract sound. Heights are metres above local ground.
5. **Run grid** — produces the contour raster. Drag any source to extrapolate immediately; the snapshot refreshes in the background.
6. **Export** — receiver totals (CSV/XLSX), per-source contributions, per-band spectra, contour lines (KML/SHP), the grid raster (GeoTIFF), and a PDF map.
