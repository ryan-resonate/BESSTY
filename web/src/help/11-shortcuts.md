---
title: Keyboard shortcuts
section: Reference
---

| Key | Action |
| --- | --- |
| Esc | Cancel any active add, measure or barrier mode, and clear the selection |
| Del or Backspace | Delete the current selection |
| Ctrl + Z | Undo, 50 entries deep |
| Ctrl + Shift + Z, or Ctrl + Y | Redo |
| Ctrl + C | Copy the selection |
| Ctrl + V | Paste at the cursor, across projects and tabs |
| Shift + click | Toggle membership in the selection |
| Left drag on empty map | Box-select sources and receivers |
| Middle drag | Pan the map |

Copy and paste carry a JSON envelope on the clipboard, so a copy in one project pastes into another. Pasting preserves the relative layout of the copied objects, centred on the mouse.

Display settings are not on the undo stack — Ctrl+Z undoes model edits, never a view change.
