# Share links are public capability URLs — the 32-character token in the path
# is the whole of the authorisation. A crawler that followed one would publish
# it into a search index, which turns an unguessable link into a listed one.
#
# NOTE: inert on the current deployment. CI builds with BESSTY_BASE=/BESSTY/,
# so this is served at /BESSTY/robots.txt, and crawlers only honour a
# ROOT-level /robots.txt — which belongs to the ryan-resonate.github.io root
# and is not ours to write. The `noindex` meta tag in index.html is what
# actually holds today. Kept because this becomes effective the moment BESSTY
# is served from a domain root, and because the cost of keeping it is nil.
User-agent: *
Disallow: /share/
Disallow: /
